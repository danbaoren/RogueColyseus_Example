## About

Colyseus implementation in Rogue Engine

Connects scene to Colyseus, reads all avatars, sends messages between them

Simple position sync

# Installation

1. Start Colyseus server: inside Colyseus_Server open cmd and type <u>npm start</u>

2. Copy Assets folder inside your game project directory

3. Move <u>Colyseus/ColyseusRoomManager</u> to scene (main network manager)

4. Put <u>Colyseus/LocalTransformSync</u> to your player character (rapier third person as example). (It sends location and rotation to all players online)
